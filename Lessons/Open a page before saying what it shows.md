# Open a page before saying what it shows

*Written 2026-11-03.*

## What happened

Claude caught this when asked to update the older pages. An earlier Journal entry said `balance.html` prints the $841M reading of free cash flow, and Claude repeated that to me and in a later entry without opening the page. The only $841M on `balance.html` is a debt amount in the ladder, a book value from the [10-K, filed Feb. 12, 2026](https://www.sec.gov/Archives/edgar/data/24741/000002474126000124/glw-20251231.htm). A text match on the number had been read as the same figure. No decision used it.

## What it taught us

The same digits can be a different figure. Read the words around a number before saying a page shows it, and check an old note's claim about a file before repeating it.

## What changed

`balance.html` was left as it is, because it needs no fix. The Journal says so in a new entry, and the earlier entries stand as written. No rule changed.
