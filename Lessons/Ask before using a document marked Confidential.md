# Ask before using a document marked Confidential

*Written 2026-11-03.*

## What happened

I caught this. Claude used rival capacity estimates from an outside investor's slides in `rivals.html`, [[Corning]] and [[STL]]. Every slide carried a "Confidential" footer, and one said it was for internal use and not to be circulated. Claude read that, judged it was not an inside tip because the file was on a public site, and used it. It told me only after the page was built. I told it to drop the figures. No decision used them.

## What it taught us

A public URL does not settle what a "Confidential" marking means. That judgment is mine, so Claude asks before using the document, not after.

## What changed

The figures, and every sum made from them, are out of `rivals.html`, [[Corning]] and [[STL]]. The page now sizes only HFCL and world preform. Cached copies were deleted. The Journal's earlier entry stands and holds none of the figures. No rule changed.
