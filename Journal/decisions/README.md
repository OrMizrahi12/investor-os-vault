# Decisions

One dated file per portfolio decision, written by the `coach` subagent. Each holds my own view, written before anything was shown, then the system's view and where the two differ.

Name: `YYYY-MM-DD <Company>.md`. A second decision on the same company and day adds ` 2`.

These files are records. They place no order and change nothing in `Portfolio/` or `Companies/`. My own decision goes in only in my words.
