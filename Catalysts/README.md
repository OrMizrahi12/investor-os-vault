# Catalysts

Events that could change how the market sees a company. One note per catalyst, each linked to its company.

Every fact here needs a source and a date. A catalyst that has not paid off is strategic value and never counts toward covering the price.

Map for Corning: `catalysts.html`.

`sensors/radar/radar.py` writes each note's `radar checked` and "Radar" section. Write your reading under "Outcome". The `catalyst-radar` skill runs it.
